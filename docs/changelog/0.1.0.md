# dsh-notification v0.1.0

Date: 2026-08-21

本版本是首次发布, 在 agent 跑完一轮, 出错或等待审批时发出系统通知和可选 webhook.

## Highlights

- 在运行 dsh 的机器上弹出系统原生通知, 覆盖 macOS, Linux 和 Windows.
- 可选 webhook POST, 载荷带 Slack 兼容的 `text` 字段.
- 监听 `agent/status`, `agent/error` 和 `approval/request`, 短回合可按时长过滤.

## Upgrade Notes

1. 用 `dsh plugin --profile web add dsh-notification` 安装.
2. 需要 webhook 时在 Loader 行 config 填写 `webhookUrl`.
3. 跑一轮超过 5 秒的任务, 确认系统通知出现.

## Features

- 桌面通知: macOS `osascript`, Linux `notify-send`, Windows PowerShell toast, 失败吞掉.
- 事件: 回合结束 (`agent/status`, 默认至少 5 秒), 出错 (`agent/error`), 审批等待 (`approval/request`, 只观察并 `next()`).
- 监听按 effect 注册, 卸载和热重载会自动摘掉.
