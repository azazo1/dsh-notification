# dsh-notification v0.1.1

Date: 2026-08-21

本版本补上浏览器通知渠道, 让远端 server 场景下也能在看 Web UI 的机器上收到提醒.

## Highlights

- Web UI 在标签页隐藏时弹出浏览器 `Notification`, 覆盖远端 server 拓扑.
- `@deepseek-ai/schemastery` 改为 peer dependency, 运行时共用一份.
- 增加冒烟测试和 Node CI.

## Upgrade Notes

1. 重新安装或更新插件, 确认 Web profile 能加载 `./client` 入口.
2. 首次点击或按键后允许浏览器通知权限.
3. 本机同时开系统通知和浏览器通知时, 同一事件会弹两次, 可关其中一条渠道.

## Features

- 浏览器通知: 盯着 client session list, 回合结束或等待用户时弹窗.
- 新配置: `browser` (默认 `true`), `browserOnlyWhenHidden` (默认 `true`).
- 冒烟测试覆盖回合结束, 出错, 审批委托和时长门限.
